Before you study

Exam blueprint

The Cloud Practitioner exam tests whether you can recognize what AWS services do and when to use them — not whether you can configure them. You will never be asked to write code or read a console screenshot. Almost every question is a short scenario followed by "which service / option / plan fits?" That means the winning study strategy is breadth: know one clear sentence about many services, rather than deep detail about a few.

Domain 1 — 24% of scored content

Cloud concepts

In plain language: cloud computing means renting IT resources over the internet and paying only for what you use, instead of buying and running your own servers. This domain tests the vocabulary and the "why" — why companies move to the cloud, what the different flavors are, and how AWS says you should design and migrate.

1.1 The six advantages of cloud computing

AWS's official list. Exam questions describe one of these in a scenario and ask you to name it — learn the exact phrases.

  1. 1Trade fixed expense for variable expense — no upfront capital purchase (CapEx); pay as you consume (OpEx). Trigger phrase: "no longer buys servers upfront."
  2. 2Benefit from massive economies of scale — AWS buys hardware for millions of customers, so unit prices are lower than you could get alone.
  3. 3Stop guessing capacity — scale up and down with actual demand instead of over-buying "just in case" or under-buying and failing.
  4. 4Increase speed and agility — new resources are a click away, so teams experiment in minutes, not procurement cycles.
  5. 5Stop spending money running and maintaining data centers — no racking, powering, cooling, or patching hardware.
  6. 6Go global in minutes — deploy to Regions around the world for low latency to your users.

1.2 Cloud service models — who manages what

The more managed the service, the less you operate yourself. The color grid below is worth memorizing: it also explains the shared responsibility model in module 2.

Runtime and middlewareYouYouAWSProvider

  • IaaS (Infrastructure as a Service): raw building blocks — compute, storage, network. Maximum control, maximum responsibility. Example: EC2.
  • PaaS (Platform as a Service): you bring code and data; AWS runs the platform underneath. Examples: Elastic Beanstalk, RDS, Lambda.
  • SaaS (Software as a Service): a finished product you just use. Examples: most third-party apps in AWS Marketplace.

1.5 The Well-Architected Framework — six pillars

AWS's official design checklist. Memorize all six with the mnemonic "CROPS + Sustainability". Questions quote a pillar's goal and ask you to name it.

CCost optimization

Deliver value at the lowest price: right-size, use the best pricing model, measure spend.

RReliability

Recover from failures and meet demand: multi-AZ, automatic recovery, tested backups.

OOperational excellence

Run and improve: automate changes, operations as code, learn from failures.

PPerformance efficiency

Use resources efficiently: pick the right instance types, go serverless, experiment.

SSecurity

Protect data and systems: least privilege, encrypt everywhere, traceability.

+SSustainability

Minimize environmental impact: maximize utilization, reduce waste.

Exam tip. "Ability to recover quickly from disruption" = Reliability. "Using computing resources efficiently" = Performance efficiency. "Traceability / least privilege" = Security. The AWS Well-Architected Tool (free, in the console) reviews your workload against the pillars.

1.6 Cloud economics

  • CapEx vs OpEx: on-premises = capital expense up front; cloud = operational expense as you go.
  • Total Cost of Ownership (TCO): when comparing on-prem to AWS, count everything you stop paying for — hardware, power, cooling, real estate, and the staff time to maintain it.
  • Right-sizing: match instance size to real usage; the biggest lever for savings.
  • Managed services save money indirectly: RDS costs more per hour than a self-run database on EC2, but eliminates patching, backup, and failover labor — total cost is usually lower.
  • Estimate before you build with the AWS Pricing Calculator (module 4 covers all cost tools).

1.7 Migration: the CAF and the 7 Rs

The AWS Cloud Adoption Framework (CAF) organizes migration advice into six perspectives — three about people, three about technology:

Business capabilitiesTechnical capabilities
Business — cloud investment ties to business outcomesPlatform — build and modernize the infrastructure
People — culture, skills, trainingSecurity — confidentiality, integrity, availability of data
Governance — manage risk, measure benefitsOperations — run workloads to meet business needs

The 7 Rs — migration strategies, from least to most change:

StrategyPlain meaning
RetireTurn it off — nobody uses it
RetainLeave it where it is (for now)
Rehost"Lift and shift" — move as-is onto EC2, no code changes
RelocateMove at the hypervisor level, e.g. VMware environment into AWS
Replatform"Lift, tinker, and shift" — small upgrades on the way, e.g. self-run MySQL to RDS
RepurchaseDrop it and buy a SaaS product instead
RefactorRe-architect for cloud-native (serverless, microservices) — most effort, most benefit

Security and compliance

This is the second-largest domain, and half of it comes down to one picture: the Shared Responsibility Model. Expect 3–6 questions on it alone.

2.1 The Shared Responsibility Model

Plain version: AWS secures the cloud itself; you secure whatever you put in it.

Scenario in the questionWhose job?Why
Patching the guest operating system on an EC2 instanceYouIaaS — you control the OS

Security group and firewall rules; your application codeYouYour network and app choices

2.2 IAM — who can do what

Identity and Access Management (IAM) is free, global (not tied to a Region), and controls every action in your account.

Building blockWhat it isRemember

IAM userA person or application with long-term credentials (password / access keys)One user per person — never share credentials
GroupA collection of usersAttach policies to groups, not individuals — easier to manage
RoleAn identity with temporary credentials that users, apps, or AWS services assumeThe answer whenever a question says "an EC2 instance needs to access S3" or "grant temporary / cross-account access" — never hard-code access keys
PolicyA JSON document that allows or denies actions on resourcesApply least privilege: grant only what's needed. An explicit Deny always wins
IAM Identity CenterSingle sign-on for your workforce across many AWS accounts and appsThe modern answer for "employees log in once"
Exam tip. IAM best practices the exam loves: enable MFA (especially on root), grant least privilege, use roles for applications and services, use groups to assign permissions, rotate credentials, and never share access keys.

2.6 Compliance and data protection

  • AWS Artifact — self-service portal to download AWS's own compliance reports (SOC, PCI DSS, ISO) and agreements. Free. The answer to any "our auditors need proof AWS is compliant" question.
  • AWS Audit Manager — continuously collects evidence from your account for your audits.
  • Compliance is shared: AWS certifies the infrastructure; you are still responsible for your workload's compliance (e.g. how you handle customer data under GDPR or HIPAA).
  • Encryption in transit = TLS/HTTPS (certificates from ACM). Encryption at rest = keys from KMS; available in S3, EBS, RDS, and virtually every storage service — but enabling and configuring it is your job.
  • Data residency: your data stays in the Region you choose; AWS does not move it. Choosing a compliant Region is your decision.

Domain 4 — 12% of scored content

Billing, pricing and support

4.1 How AWS pricing works

  • Pay as you go — per second/hour/request/GB, no contracts required.
  • Pay less when you commit — Reserved Instances and Savings Plans.
  • Pay less with volume — tiered pricing: the more S3 you store, the cheaper each GB.
  • Data transfer: traffic into AWS is free; traffic out to the internet is charged; traffic between Regions and between AZs also costs money.

4.4 AWS Organizations — many accounts, one bill

  • A management account governs many member accounts, grouped into organizational units (OUs).
  • Consolidated billing: one invoice for all accounts, usage pooled so everyone benefits from volume-tier discounts, and Reserved Instance / Savings Plan discounts are shared across accounts.
  • Service control policies (SCPs) set the maximum permissions for member accounts — guardrails that even a member account's admins can't exceed (e.g. "no one may leave the approved Regions").
  • AWS Control Tower automates setting up a well-governed multi-account environment on top of Organizations.

Highest-yield pages in the course

Exam strategy and the keyword cheat sheet

5.1 How to take the exam

  • Eliminate first. Two options are usually obviously wrong; you're choosing between the last two.
  • Obey the qualifier. MOST cost-effective, LEAST effort, HIGHLY available — when two answers both "work," the qualifier picks the winner. Managed and serverless beat self-managed for "least effort"; Spot beats everything for "cheapest interruptible."
  • Multiple-response questions state the count ("Select TWO") — pick exactly that many; no partial credit.
  • Never leave blanks. There is no penalty for guessing. Flag, guess, move on.
  • Watch scope words. "Global" services: IAM, Route 53, CloudFront, Organizations. Most everything else is Regional; EBS volumes and subnets are per-AZ.
  • Pace: 80 seconds per question on average. First pass everything, then revisit flagged ones.

Practice questions

Written in the real exam's style. Answer before opening the explanation; anything you miss, re-read that module section.

Domain 1 — Cloud concepts

1. A company closes its data center and stops buying servers upfront, paying instead for compute as it is consumed. Which advantage of cloud computing does this describe?

  • A. Massive economies of scale
  • B. Trade fixed expense for variable expense
  • C. Go global in minutes
  • D. Increased deployment speed
Show answer

B. Upfront capital purchases (fixed/CapEx) replaced by pay-per-use (variable/OpEx) is the textbook phrase. Economies of scale (A) is about AWS's bulk purchasing lowering prices, not your payment model.

Domain 1 — Cloud concepts

2. Which Well-Architected Framework pillar focuses on the ability of a workload to recover from infrastructure disruptions?

  • A. Performance efficiency
  • B. Operational excellence
  • C. Reliability
  • D. Cost optimization
Show answer

C. Reliability = recover from failures and meet demand. Operational excellence (B) is about running and improving processes, a common distractor.

Domain 1 — Cloud concepts

3. Which statement best describes elasticity?

  • A. Deploying resources in multiple Regions
  • B. Automatically acquiring and releasing resources as demand changes
  • C. Replacing servers with larger ones
  • D. Running workloads on redundant hardware
Show answer

B. Elasticity is automatic and two-directional — grow with demand, shrink when it falls, and pay accordingly. C describes vertical scaling; D describes fault tolerance.

Domain 2 — Security and compliance

4. Under the shared responsibility model, which task is the customer's responsibility for an application running on Amazon EC2?

  • A. Patching the guest operating system
  • B. Physical security of the data center
  • C. Maintaining the virtualization hypervisor
  • D. Disposing of decommissioned disk drives
Show answer

A. On EC2 you control the OS, so you patch it. Everything physical or at the hypervisor layer (B, C, D) is AWS — security OF the cloud.

Domain 2 — Security and compliance

5. A company must discover personally identifiable information (PII) stored across its S3 buckets. Which service should it use?

  • A. Amazon GuardDuty
  • B. Amazon Inspector
  • C. AWS Shield
  • D. Amazon Macie
Show answer

D. Macie = ML that finds sensitive data in S3. GuardDuty detects threats, Inspector finds vulnerabilities, Shield stops DDoS — all common distractors here.

Domain 2 — Security and compliance

6. A web application behind an Application Load Balancer must be protected from SQL injection attacks. Which service should be used?

  • A. AWS Shield
  • B. AWS WAF
  • C. Amazon GuardDuty
  • D. Network ACLs
Show answer

B. WAF filters web requests for exploit patterns like SQL injection and XSS. Shield (A) is specifically DDoS; NACLs (D) filter by IP/port, not request content.

Domain 2 — Security and compliance

7. Which TWO are AWS Identity and Access Management best practices? (Select TWO)

  • A. Enable multi-factor authentication on the root user
  • B. Share one set of access keys across the team
  • C. Grant permissions following least privilege
  • D. Use the root user for daily administration
  • E. Embed access keys in application code
Show answer

A and C. MFA on root and least privilege are the two canonical practices. B, D, and E are each the exact opposite of a best practice (use individual users, lock root away, use roles instead of embedded keys).

Domain 3 — Technology and services

8. A nightly analytics batch job can tolerate interruptions and restarts. Which EC2 purchasing option costs the least?

  • A. On-Demand Instances
  • B. Reserved Instances
  • C. Spot Instances
  • D. Dedicated Hosts
Show answer

C. "Tolerates interruption" + "least cost" is the Spot signature (up to ~90% off). Reserved (B) suits steady always-on workloads; Dedicated Hosts (D) are the most expensive option.

Domain 3 — Technology and services

9. Multiple Linux EC2 instances in different Availability Zones must read and write the same set of files at once. Which storage service fits?

  • A. Amazon EBS
  • B. Amazon EFS
  • C. EC2 instance store
  • D. Amazon S3 Glacier
Show answer

B. EFS is the shared, multi-AZ file system. EBS (A) attaches to a single instance in a single AZ; instance store (C) is temporary; Glacier (D) is archive, not a mountable file system.

Domain 3 — Technology and services

10. An analyst wants to run standard SQL queries against CSV files already stored in Amazon S3, without provisioning any infrastructure. Which service should they use?

  • A. Amazon Redshift
  • B. Amazon RDS
  • C. Amazon Athena
  • D. Amazon EMR
Show answer

C. Athena = serverless SQL directly on S3, pay per query. Redshift (A) is a provisioned data warehouse you'd load data into; EMR (D) means managing a big-data cluster.

Domain 3 — Technology and services

11. An e-commerce app must decouple order intake from order processing so each order is stored durably and processed once, even if the processor is temporarily down. Which service fits?

  • A. Amazon SNS
  • B. Amazon SQS
  • C. Amazon SES
  • D. Amazon Kinesis
Show answer

B. A queue holds messages until a consumer processes them — the definition of decoupling with durability. SNS (A) pushes to whoever is subscribed right now; Kinesis (D) is for real-time streaming analytics.

Domain 3 — Technology and services

12. A company wants its Amazon RDS database to keep running if one Availability Zone fails. What should it enable?

  • A. Read replicas
  • B. Automated snapshots
  • C. A larger instance class
  • D. Multi-AZ deployment
Show answer

D. Multi-AZ keeps a synchronized standby in another AZ and fails over automatically = availability. Read replicas (A) improve read performance; snapshots (B) are backups, not failover.

Domain 3 — Technology and services

13. Security auditors need a record of every API call made in the AWS account, including who made it and when. Which service provides this?

  • A. Amazon CloudWatch
  • B. AWS CloudTrail
  • C. AWS Config
  • D. Amazon Inspector
Show answer

B. CloudTrail = who did what, when (API audit log). CloudWatch (A) is performance metrics; Config (C) is resource configuration history — the two classic distractors.

Domain 4 — Billing, pricing and support

14. Which is the lowest-cost AWS Support plan that includes 24/7 phone access to cloud support engineers and the full set of Trusted Advisor checks?

  • A. Basic
  • B. Developer
  • C. Business
  • D. Enterprise
Show answer

C. Business is the first tier with 24/7 phone/chat and full Trusted Advisor. Developer (B) is business-hours email only; Enterprise (D) also qualifies but is not the lowest cost.

Domain 4 — Billing, pricing and support

15. A company runs 40 AWS accounts and wants a single invoice with usage combined so all accounts benefit from volume discounts. What should it use?

  • A. AWS Cost Explorer
  • B. Consolidated billing in AWS Organizations
  • C. AWS Budgets
  • D. A Compute Savings Plan
Show answer

B. Consolidated billing = one bill, pooled usage tiers, shared RI/Savings Plan discounts. Cost Explorer and Budgets analyze and alert — they don't combine invoices.

Domain 4 — Billing, pricing and support

16. Before migrating, a team must estimate the monthly cost of a planned three-tier architecture. Which tool should they use?

  • A. AWS Cost Explorer
  • B. AWS Pricing Calculator
  • C. Cost and Usage Report
  • D. AWS Budgets
Show answer

B. Pricing Calculator estimates costs for things you haven't built yet. Cost Explorer (A) and the Cost and Usage Report (C) analyze spend that has already happened; Budgets (D) alerts on thresholds.
